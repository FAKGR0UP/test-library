# Guía de Instalación

Sigue estos pasos para instalar nuestra biblioteca en tu sistema.

## Instalación rápida

```bash
npm install our-library
```

## Instalación manual

### Prerrequisitos

1. **Node.js**: versión 18 o superior
2. **Gestor de paquetes**: npm, yarn o pnpm

### Paso 1: crear un proyecto

```bash
mkdir mi-proyecto
cd mi-proyecto
npm init -y
```

### Paso 2: instalar la biblioteca

```bash
npm install our-library
```

### Paso 3: verificar la instalación

```bash
npx our-library --version
```

## Plataformas

### Windows

En Windows puede que necesites PowerShell como administrador para instalaciones globales.

### macOS

En macOS puede que necesites `sudo` para instalaciones globales.

### Linux

En Linux puede que necesites `sudo` para instalaciones globales.
